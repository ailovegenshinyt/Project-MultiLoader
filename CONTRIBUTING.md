# 🤝 Contributing to MultiLoader

Thanks for your interest in contributing! We welcome developers, designers, and enthusiasts of all skill levels.

---

## 🎯 How to Contribute

### 🐛 Report Bugs
Found a bug? [Open an issue](https://github.com/ailovegenshinyt/Project-MultiLoader/issues) with:
- Steps to reproduce
- Expected vs actual behavior
- Your OS & Python version
- Screenshots/logs if helpful

### 💡 Suggest Features
Have an idea? Start a [discussion](https://github.com/ailovegenshinyt/Project-MultiLoader/discussions) or [open an issue](https://github.com/ailovegenshinyt/Project-MultiLoader/issues) labeled `enhancement`.

### 🔧 Submit Code
1. **Fork** the repo
2. **Create a branch:** `git checkout -b feature/your-feature`
3. **Make changes** & test locally
4. **Commit:** `git commit -m "✨ Add your feature"`
5. **Push:** `git push origin feature/your-feature`
6. **Open a Pull Request** with a clear description

---

## 📋 Development Setup

### Prerequisites
- Python 3.9+
- Git
- FFmpeg (for media processing)

### Local Setup
```bash
# Clone your fork
git clone https://github.com/YOUR-USERNAME/Project-MultiLoader.git
cd Project-MultiLoader

# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
```

---

## 📝 Code Standards

- **Python:** Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/)
- **Naming:** Use clear, descriptive names
- **Comments:** Document complex logic
- **Testing:** Test locally before submitting PR

### Example Commit Message
```
✨ Add TikTok support
- Implement TikTok URL parsing
- Add quality selection for TikTok videos
- Test with sample URLs
```

---

## 🎨 Design Guidelines

- **UI/UX:** Maintain the Liquid Glass aesthetic
- **Responsiveness:** Test on mobile devices
- **Accessibility:** Ensure keyboard navigation works
- **Performance:** Minimize CSS/JS bundle size
